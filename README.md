# Screen Recorder

A simple screen recorder for Linux. Records your screen with computer
sound and an optional microphone. Works on Wayland and X11.

## Install (Ubuntu, Debian, Mint)

1. Download the latest `.deb` from the Releases page.
2. Install it:

       sudo apt install ./screenrec_1.1.1.deb

3. Open "Screen Recorder" from your app menu.

Recordings are saved to your Videos folder as `.mkv` files.

## Build from source

    git clone https://github.com/YOURNAME/screenrec.git
    cd screenrec
    ./build-deb.sh 1.1.1
